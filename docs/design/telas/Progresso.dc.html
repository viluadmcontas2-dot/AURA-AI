Como o percentual é calculado

Soma de cada área: pesos vezes feito dividido por total. Os pesos são uma escolha minha (telas 30, reforma de apps 10, estados 15, sistema 15, fluxo 10, contrato 10, entrega ao código 5, teste com pessoa real 5). Mude os pesos se quiser outra régua.

O que falta para chegar a 100%

Entregar os arquivos de design ao repositório para o GPT codar, e testar o fluxo com uma pessoa real tocando no protótipo. Só então a nota visual de 0 a 4 do seu Product Design Studio faz sentido.
