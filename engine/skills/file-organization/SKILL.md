# Safe File Organization
List first, compare duplicates by content hash rather than filename, and map each source to the desired destination. Distinguish canonical source, temporary generated output, downloaded data and personal private files. Work within explicitly selected workspaces and Android storage grants. Provide a proposed change list; preserve backups and undo mapping before every move. Never delete source files in an initial pass, or modify shared Drive content without confirmation. Report concrete modified paths, counts, failures and evidence. Do not claim organization is complete if files were not inspected.
