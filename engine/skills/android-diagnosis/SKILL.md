# Android Diagnosis
Discover capabilities locally. Check if the intended Android target is paired and authorised. Never confuse an IP or port response with an authenticated ADB connection. Read-only order: adb devices -l, getprop, dumpsys and bounded logcat, then screenshots with sensitive data protected. Capture actual command exit codes and timestamps. Explain observed failure and its likely cause without guesswork. Do not tap, reboot, install, clear app data, change device security settings or write to an ECU without a separate target-specific approval. Avoid collecting serials or tokens in shared logs. Report FEITO, COMPROVADO with evidence, FALTA and one PRÓXIMO PASSO.
